# lab-04
# LOQ Team

Сайт для купівлі скінів Counter-Strike. Лабораторна робота №4 (Flask + SQLite).

## Опис

Багатосторінковий вебзастосунок **LOQ Market** для перегляду та замовлення скінів зброї Counter-Strike 2 на **Flask** та **SQLite**. Сайт має адаптивну верстку й коректно відображається як на смартфонах, так і на персональних комп'ютерах.

У 4-й лабораторній роботі застосунок підключено до реляційної бази даних SQLite (`instance/loq_market.sqlite3`) та розширено таким функціоналом:
- **Каталог із пошуком, фільтрами та вкладеними категоріями** — пошук скінів, фільтрація за ієрархічними категоріями, зброєю, станом, ціною й наявністю, а також сортування.
- **Система користувачів і ролей (`admin` / `customer`)** — реєстрація, вхід, одноразове налаштування першого адміністратора та розмежування доступу до замовлень і адмін-панелі.
- **Замовлення, залишки та промокоди** — оформлення замовлень зі списанням товару зі складу, перегляд історії замовлень клієнта, керування статусами замовлень із поверненням залишків при скасуванні та система знижок за промокодами (стартовий код `LOQ10` — 10%).
- **Обране та відгуки** — збереження товарів у список обраного (`favorites`) і форма зворотного зв’язку зі збереженням у БД (`feedback`).
- **Адмін-панель** — CRUD-операції для товарів, вкладених категорій, користувачів, замовлень, промокодів і відгуків.

## Сторінки

- **Головна (`/`)** — вступний блок і добірка популярних скінів
- **Магазин (`/shop`)** — каталог скінів із цінами, зображеннями, пошуком, фільтрацією, сортуванням, активними промокодами та додаванням в обране
- **Оформлення замовлення (`/shop/<id>/order`)** — замовлення скіну з вибором кількості, перевіркою залишку та введенням промокоду (після входу)
- **Обране (`/favorites`)** — збережені користувачем скіни
- **Мої замовлення (`/account`)** — особиста історія замовлень користувача зі статусами, промокодами та підсумковою сумою
- **Автентифікація (`/login`, `/register`, `/setup/admin`)** — вхід, реєстрація клієнта та початкове створення адміністратора
- **Про нас (`/about`)** — інформація про нашу команду з посиланнями на каталог і зворотний зв'язок
- **Зворотний зв'язок (`/contacts`)** — пошта, телефон, графік роботи та форма для надсилання відгуку до БД
- **Адмін-панель (`/admin/*`)** — керування товарами й вкладеними категоріями (`/admin/products`), користувачами та їхніми замовленнями (`/admin/users`), замовленнями й статусами (`/admin/orders`), промокодами (`/admin/promocodes`) та відгуками (`/admin/feedback`)

## Технології

- Python 3
- Flask 3.1.3
- SQLite (`sqlite3`)
- HTML5 / Jinja2 + Tailwind CSS 4 (CDN)

## Запуск проєкту

1. Клонуйте репозиторій:

```bash
git clone https://github.com/illuwka/lab04.git
cd lab04
```

2. (Рекомендовано) створіть і активуйте віртуальне середовище:

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS (bash/zsh)
source .venv/bin/activate
```

3. Встановіть залежності:

```bash
pip install -r requirements.txt
```

4. Запустіть застосунок:

```bash
python app.py
```

Під час першого запуску автоматично створюється база даних `instance/loq_market.sqlite3` із початковими товарами, категоріями, промокодом `LOQ10` і тестовими даними. Під час першого відкриття створіть обліковий запис адміністратора за посиланням **Перший адміністратор** (`/setup/admin`). Інші користувачі реєструються як клієнти (`/register`). Замовлення та список **Обране** доступні після входу, а історія замовлень — у розділі **Мої замовлення**.

## Lab4: товари, користувачі та замовлення

- Дані зберігаються у SQLite: `instance/loq_market.sqlite3`.
- `users` зберігає ім'я, email, роль (`admin` або `customer`) і пароль у відкритому тексті.
- `orders` зберігає замовлення зі статусом, зв'язком з користувачем (`user_id`) та використаним промокодом; `order_items` пов’язує замовлення з товарами (`products`).
- Склад зменшується під час оформлення; під час скасування замовлення товар повертається. Повторне відновлення замовлення перевіряє залишок.
- Клієнт переглядає лише власну історію замовлень. Доступ до адмін-панелі перевіряє роль користувача.
- `/admin/promocodes` — створення, редагування та вимкнення промокодів, відсотка знижки, дати завершення й ліміту використань. Початковий код `LOQ10` дає 10% знижки.
- Адмін-панель:
  - `/admin/products` — створення, редагування та видалення товарів.
  - `/admin/users` — керування користувачами (ім'я, email), перегляд та редагування їхніх замовлень (статус, товар, кількість, сума), створення нових замовлень та видалення.
  - `/admin/orders` — централізований перегляд усіх замовлень та зміна статусів.
  - Швидке перемикання між товарами, користувачами, замовленнями, промокодами та відгуками за допомогою панелі навігації.
- Під час першого запуску старі замовлення та користувачі автоматично синхронізуються.
